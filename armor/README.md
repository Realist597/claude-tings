# Dark Knight armour (R6)

Black steel plate with purple metal trim, a purple cloth skirt and hood, and black leather. It's based on
`reference.jpg`, recoloured, and fitted to the R6 body in `r6_rig_body.fbx`.

## What's in `export/`

| File | What it is |
|---|---|
| `ArmorKit.fbx` | Six armour meshes (`Armor_Head`, `Armor_Torso`, `Armor_LeftArm`, `Armor_RightArm`, `Armor_LeftLeg`, `Armor_RightLeg`) plus six `Ref_*` parts: the R6 body they were fitted to |
| `Armor_<Part>_Color.png` | Base colour (sRGB) |
| `Armor_<Part>_Normal.png` | Tangent-space normal map, OpenGL (+Y), which is what Roblox expects |
| `Armor_<Part>_Roughness.png` | Roughness |
| `Armor_<Part>_Metalness.png` | Metalness |
| `preview.png`, `preview_closeup.png` | Renders using the baked maps, so they show what Roblox will show |

Every mesh stays under Roblox's 20,000-triangle limit, and every texture is 1024 × 1024.

## Putting it in your game

1. **Import:** in Studio, go to Avatar → Import 3D (or File → Import 3D) and pick `ArmorKit.fbx`. Import it as one model.
2. **Textures:** select each `Armor_*` MeshPart and add a **SurfaceAppearance** if the importer didn't make one.
   Set its `ColorMap`, `NormalMap`, `RoughnessMap` and `MetalnessMap` to that part's four PNGs.
3. **Store it:** rename the model to `DarkKnightArmor` and move it into **ServerStorage**.
4. **Script:** put `DarkKnightArmor.server.lua` in **ServerScriptService** as a Script.

Players now spawn wearing the armour. Each piece is welded to its body part, so it moves with R6 animations.
Hats and hair are removed so they don't poke through the helm. Turn that off with `HIDE_ACCESSORIES`
in the script.

If the armour comes in facing backwards, set `FLIP = true` in the script.

## Rebuilding

Everything is generated by `build_armor.py`, using Blender 4.2+ or the pip `bpy` module:

```
python build_armor.py -- --stage preview          # quick look with live materials
python build_armor.py -- --stage all --res 1024   # bake maps, render previews, export FBX
```

Colours are set in `materials()`, and each piece's shape is in `helmet()`, `torso()`, `arm()` and `leg()`.
